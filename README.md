# MarketScope

Free-first market and macroeconomic research terminal. Built with React, TypeScript, TanStack Start and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Market data is sourced from attributed third-party providers. TradingView widgets may be delayed; macro series are retrieved from FRED; company fundamentals use SEC EDGAR. Portfolio and preferences are stored locally in the browser. Educational use only; not investment advice.
